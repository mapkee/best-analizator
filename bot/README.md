# Обработчик @shashkamovebot

Cloudflare Worker отвечает на `/start` тремя кнопками:

1. **Открыть приложение** — запускает анализатор внутри Telegram.
2. **Как пользоваться** — отправляет инструкцию прямо в чат.
3. **Написать разработчику** — открывает https://t.me/mapkee.

Сайт продолжает работать на GitHub Pages. Worker обрабатывает только сообщения
Telegram; база данных для этой реализации не нужна.

## Установка через Cloudflare Dashboard

1. Создай Worker `shashkamovebot` через **Start with Hello World!**.
2. В **Edit code** замени весь пример содержимым [worker.mjs](worker.mjs).
   Оставь имя файла, предложенное редактором Cloudflare, и нажми **Deploy**.
3. В **Settings → Variables and Secrets** добавь два значения типа **Secret**:
   - `BOT_TOKEN` — токен @shashkamovebot из BotFather;
   - `WEBHOOK_SECRET` — собственная случайная строка длиной от 32 до 256 символов
     из латинских букв, цифр, дефиса и подчёркивания.
4. Сохрани изменения и разверни новую версию, если Cloudflare предложит Deploy.
5. Открой `https://<адрес-worker>/setup`, введи **WEBHOOK_SECRET** и нажми
   **Подключить бота**. Это значение не является токеном Telegram.
6. После подтверждения отправь `/start` в @shashkamovebot и проверь три кнопки.

Страница `/setup` проверяет имя бота, подключает webhook и кнопку меню.
Если обнаружен другой webhook, настройка остановится без его замены.
Кнопка Main Mini App в профиле настраивается отдельно через BotFather.

Токен и секрет нужно вводить только в Cloudflare, не в исходный код и не в чат.
Worker не выводит их в ответы и не записывает сообщения пользователей в журналы.
Telegram может повторно доставлять обновления; при сбое связи возможен повтор ответа.

## Проверка локально

```sh
node tests/bot.mjs
```

Тесты не обращаются к Telegram. Они проверяют меню, инструкцию, проверку секрета,
настройку webhook и обработку ошибок.

Для публикации через Wrangler в корне репозитория есть `wrangler.toml`.
