# Шесть взятий за один ход

Запись настоящего интерфейса OneStep: белая шашка проходит серию из шести
взятий, превращается в дамку и завершает партию победой с салютом.

- [MP4-анимация для Telegram](six-capture.mp4), 720 × 900, 7 секунд, без звука.
- [GIF для просмотра](six-capture.gif).
- [Исходная позиция и маршрут](six-capture.json).

Кадры получены из интерфейса приложения через его обработчики ходов.
Для ролика скрыта боковая панель и замедлено воспроизведение анимации;
правила и результаты взятий не подменяются. Это демонстрационная позиция,
а не запись партии против другого человека.

Проверка: `node tests/demo.cjs`.
